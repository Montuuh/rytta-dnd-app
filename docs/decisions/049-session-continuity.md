# ADR 049: campaign session continuity

Date: 2026-11-19. Status: accepted.

Closing a game session records one current handoff per campaign. The DM chooses the encounter to resume, records pending rewards and a next scene, and can keep a private note. Each successful close replaces the current handoff. A revision check keeps a second device from overwriting a newer save. The wizard keeps the last saved values when the DM skips a step.

The optional player recap is a separate record. The DM writes the text for players explicitly. Withdrawing the recap removes it from the player view. Combat history remains with the encounter and item deliveries retain their own receipts. Handing out items takes effect on confirmation even if the DM later leaves the session wizard.
